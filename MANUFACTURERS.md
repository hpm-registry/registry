# Canonical Manufacturer Names

This is the **single source of truth** for the `manufacturer` field in component entries.
Use the exact string listed here — no abbreviations, no punctuation variants.

If a manufacturer you need is not listed, add them in the same PR as your component entry.
Place them in the correct alphabetical position. Do not add subsidiaries that have been
fully absorbed (e.g. Linear Technology → Analog Devices, Maxim Integrated → Analog Devices).
